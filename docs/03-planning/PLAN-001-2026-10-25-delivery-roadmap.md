## 4. 实施前仍需确定

1. 已确定首个网站为GitHub Trending每日榜，采集项目README；流程、默认参数、输出格式和恢复设计见 [插件流程设计](../02-design/DES-004-2026-10-25-plugin-workflows.md)。项目数与间隔可配置，原始Markdown需求尚未确认，首版提取渲染正文并标明格式。
2. 服务器系统、CPU 架构与核数、可用内存、本地磁盘和现有 NGINX 的运行位置/静态文件发布方式；已确认 CPU 资源较低、内存充足且可运行容器，默认 SQLite，域名及 HTTPS 由既有设施提供。
3. 每天期望执行的时间，网站签到的业务时区。
4. 新增与更新的关注规则，是否希望首日接收摘要。
5. iPhone 系统版本，是否接受添加到主屏幕和手动开启通知。

这些事项按后续阶段分别确认，不追溯阻塞已完成的P1/P2开发验收。实际服务器参数在用户以后部署时确认，用户已授权P3开工，具体每日时间尚未指定；页面提供09:00/Asia/Shanghai建议且日程默认关闭，用户保存启用后才自动运行。
